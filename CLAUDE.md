# Boat MD Dive Service

Static site for Boat MD Dive Service (hull cleaning / diving), Long Beach, CA.

- Static HTML/CSS/JS, no build step. Preview: `python3 -m http.server 4173` then open http://127.0.0.1:4173/.
- Files: `index.html` (includes LocalBusiness schema), `styles.css`, `script.js` (nav, service prefill, form validation, mailto fallback), `assets/images/`.
- Keep the structured data in sync when business details change.
