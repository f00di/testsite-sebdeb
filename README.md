# Boat MD Dive Service Website

Static responsive website for Boat MD Dive Service in Long Beach, CA.

## Files

- `index.html` - semantic page structure, SEO metadata, local business schema.
- `styles.css` - responsive nautical visual system and layout.
- `script.js` - mobile navigation, service prefill, form validation, and mailto fallback.
- `assets/images/` - project-local generated website imagery.

Open `index.html` directly in a browser to preview the site.
